When you add your own:

- Export a PNG of the n8n canvas after the credentials are connected and the sample run is green.
- Capture the public webhook response for one valid lead and one rejected lead.
- Crop out the spreadsheet id, the webhook URL, inbox addresses, and any credential screen.
